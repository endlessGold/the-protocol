# 알려진 이슈

> 최종 갱신: 2026-08-29

**이 파일은 더 이상 이슈 목록을 담지 않는다.**
할 일과 버그는 전부
[GitHub Issues](https://github.com/endlessGold/the-protocol/issues)에 있다.

## 왜 옮겼나

이 문서의 이전 판은 20개 항목을 파일:줄 번호와 함께 나열했는데, 초기 커밋 이후
한 번도 갱신되지 않았다. 그 결과:

- 상위 3개(코덱 버그, 네트워크↔라우팅 단절, 캐릭터 ID 하드코딩)를 포함해 상당수가
  이미 고쳐졌는데도 여전히 "Critical, 미해결"로 적혀 있었다
- 줄 번호가 전부 어긋났다
- "레거시 중복 파일"로 지목했던 `core/*.rs` 7개와 `the-protocol/` 복제본은
  이미 삭제됐다
- GitHub Issues와 번호 체계가 달라서(이 문서의 #N ≠ 이슈 #N) 서로를 인용할 때
  실제로 혼동을 일으켰다

같은 정보를 두 곳에서 관리하면 반드시 한쪽이 썩는다. 이슈 추적기 하나만 쓴다.
이 원칙은 프로젝트 루트 `ROADMAP.md`에도 명시돼 있다.
